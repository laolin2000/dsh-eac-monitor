# EAC Monitor Plugin

> 客户端悬浮监控窗插件：Token 用量 / 账户余额 / 存储空间实时监控

## 2026-10-14 变更：服务存活自动检查已移除

按用户要求，本插件已删除**所有后台服务存活检查**：

| 已移除 | 原行为 |
| --- | --- |
| `continue-watchdog.cjs`（整文件删除） | 独立进程，每 4 秒 ping `/api/eac-monitor/ping`，连续 2 次失败判定服务 down；检测到「不可达 → 恢复」后自动 POST `/api/eac-monitor/continue` 续对话 |
| `index.js` 中的看门狗拉起逻辑 | 插件加载时 spawn 上述看门狗（带单实例锁与总开关） |

连带影响：
- **「中断自动续对话」不再自动发生**；`/api/eac-monitor/continue` 端点保留，但只能手动调用。
- 数据采集（30 秒）与官方公告轮询（6 小时）不受影响，属采样而非存活检查。

## 运行方式

```
在 harness 的 profile 中作为插件加载（见 README 安装说明）
```

## 说明

- 插件需要宿主提供凭据读取与客户端日志目录；请按你的环境修改其中的绝对路径。
- 它读取账户余额需要密钥，本仓库中相关值已清空。

## 关于本仓库

- 本仓库为个人项目备份，只包含**程序本体**：不含运行时数据、日志、缓存、构建产物与任何密钥。
- 配置中的密钥一律留空，请自行填入（或改用环境变量）。
- 路径中的 `C:\Users\<you>` 表示你自己的用户目录。
